Getting started 1 / 7
01

先把手机准备好

Lociant 可以让云端模型调用手机上的应用、屏幕和系统能力。跟着这几步走，第一次使用也不会迷路。

推荐先用云端模型，配置简单，手机只负责执行动作。
02

先接入云端模型

推荐 DeepSeek。注册并复制 API Key 后填到下面，密钥只保存在这台手机上。

DeepSeek 适合第一次使用，按量计费，配置清楚

03

开启运行时

运行时是手机里的小服务。云端模型负责理解你的话，它负责真正点击、输入、读取页面。

未启动 保持运行时开启，Agent 才能操作手机。
04

给它必要的权限

无障碍权限是必需的，用来点击、输入和读取当前页面。悬浮窗、通知和摄像头按需要开启。

无障碍服务必需：操作和读取应用
需要授权
悬浮窗可选：显示运行状态
可选
05

把手机接给电脑上的 Agent

MCP 是一条标准连接，让 Codex、Claude 或其他客户端发现并调用手机工具。手机负责执行，电脑负责对话和编排。

MCP 地址 --
在设置 → 运行时 → 服务中，也可以复制完整 MCP 配置和 API 令牌。电脑和手机需要在同一个局域网。
06

本地模型，实验性功能

本地模型不需要把请求发到云端，但安装包更大，对内存和芯片要求也更高。新手建议先用 DeepSeek，之后再慢慢试。

旧手机也可以试试，只是速度和可用模型会因设备而异。
07

可以开始了

回到主页，直接说出你想做的事。先从简单任务开始，成功后再交给它更复杂的工作。

“打开微信，帮我整理未读消息” “看看 B 站有什么新动态” “打开这个新 App，帮我试试登录流程”
以后想重新看？进入“设置 → 新手引导”即可再次运行。
