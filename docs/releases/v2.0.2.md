## 更稳定的边缘运行时

v2.0.2 继续收敛 Lociant 的边缘运行时定位，重点提升 Android 和 Linux
运行时的恢复能力，并补齐面向手机、桌面和开发板的正式发布包。

- Android Rust 服务意外退出时会自动检测，并使用有界指数退避重试
- 仅在启用 `autoStart` 时恢复 Android 常驻服务
- 运行时状态会报告 llama.cpp 的健康、恢复中和离线状态
- Linux 桌面后端退出或健康检查失败时会自动监控并恢复
- 首页就绪检查增加真实的只读工具探针，避免只检查进程存在

## 发布包更完整

- 签名的 Android arm64-v8a release APK
- Linux x86_64 桌面 tar.gz、AppImage 和 Debian 安装包
- Linux aarch64 无头节点 tar.gz 和 Debian 安装包
- 为每个发布资产提供 SHA-256 校验值

## 核心范围保持收敛

Lociant 继续只聚焦本地模型、设备能力、受控连接、节点生命周期和边缘
运行时。聊天主页、通用 Agent loop、NAS、文件服务器、插件和婴儿监控
不属于核心运行时；SlumberGuard 等完整应用会独立开发，并通过明确的集成
边界使用 Lociant 提供的边缘能力。

## What's New ⚡

v2.0.2 hardens the Lociant edge runtime with recovery for unexpected Android
Rust-server exits, conditional Android service restoration, llama.cpp health
reporting, Linux desktop sidecar recovery, and a real read-only readiness probe.
It also publishes signed Android, Linux desktop, Linux aarch64 node, AppImage,
and Debian packages with SHA-256 checksums. Lociant remains focused on local
models, device capabilities, controlled connections, node lifecycle, and edge
runtime integration; chat UI, general-purpose Agent loops, NAS/file-server
features, plugins, and dedicated monitoring applications remain outside the
core runtime.
