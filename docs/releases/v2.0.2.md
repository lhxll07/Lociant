# Lociant v2.0.2

`v2.0.2` is the stable edge-runtime baseline before the SlumberGuard project
is developed as a separate application. This release focuses on runtime
reliability and keeps Lociant's scope limited to local execution, device
capabilities, controlled connections, and node lifecycle.

## Runtime reliability

- Detects unexpected Android Rust-server exits and retries with bounded
  exponential backoff.
- Restores a sticky Android service only when `autoStart` is enabled.
- Reports llama.cpp health, recovery, and offline states through the runtime
  status surface.
- Watches and recovers the Linux desktop sidecar when it exits or fails health
  checks.
- Adds a real read-only tool probe to the overview readiness check.

## Packaging

- Android arm64-v8a release APK, signed with the Lociant release key.
- Linux x86_64 tarball, Debian desktop package, and AppImage.
- Linux aarch64 headless-node tarball and Debian package.
- SHA-256 checksums for every release artifact.

## Scope

Lociant does not include a chat homepage, a general-purpose Agent loop, NAS,
file-server features, plugins, or dedicated baby-monitoring workflows. Those
are separate product concerns. SlumberGuard will consume Lociant's stable
edge capabilities through an explicit integration boundary.

## Verification

The release workflow runs Flutter dependency/build checks, Rust workspace tests,
the Linux desktop build, Android release assembly, and package generation
before creating the GitHub Release.
