## 更快、更稳的日常体验

v2.0.1 集中处理了运行时热路径：慢速或离线节点不再拖住当前请求，节点地址
会先校验再连接，工具清单加入短时缓存，Android 侧也减少了模型文件重复复制
和 IPC 重复请求。设备多、网络不稳定时，节点和工具操作会更利落。

## 配置与认证更安全

- API、节点和云模型密钥不再通过局域网配置接口回显
- Android 节点恢复局域网监听，手机工具可被其他可信节点直接调用
- 本机 UI 仍可恢复 API 令牌，并将令牌安全保存在应用本地
- 清空云 API Key 改为明确操作，普通设置更新不会误删已有密钥
- Android 可直接覆盖升级 v2.0.0，现有应用数据和配置保持不变

## 核心范围收敛，结构更清晰

模型市场、多节点、MCP 和控制 API 能力保留。核心应用现在只聚焦本地模型、
设备工具、受控连接和边缘节点网络；聊天主页、通用 Agent loop、NAS/文件
服务器和婴儿监控都不属于核心运行时。内部清理了重复状态、无效抽象和阻塞
调用，验收脚本也已适配当前工具描述格式。

## What's New ⚡

v2.0.1 improves runtime responsiveness under slow or offline peers, validates
peer addresses before connecting, reduces repeated Android model and IPC work,
and prevents API, peer, and cloud secrets from being echoed over LAN APIs. It
also adds native Debian packages for amd64 desktops and arm64 headless nodes.
The core scope is now explicit: local models, device tools, controlled
connections, MCP/control API integration, and multi-node networking. Chat UI,
general-purpose Agent loops, NAS/file-server features, and dedicated monitoring
remain outside the core runtime.
